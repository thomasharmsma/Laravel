# Viswedstrijd Management Systeem

## Over het project

Deze website is ontwikkeld om het organiseren en beheren van viswedstrijden eenvoudiger en overzichtelijker te maken. Beheerders (admins) kunnen deelnemers registreren en wedstrijden aanmaken en beheren.

### Functionaliteiten

- **Deelnemersbeheer:** Beheerders kunnen deelnemers toevoegen met hun naam en e-mailadres.
- **Wedstrijdbeheer:** Beheerders kunnen wedstrijden aanmaken met de naam, datum, locatie en het maximale aantal deelnemers.
- **Overzichtelijke interface:** De website beschikt over een gebruiksvriendelijke interface waarmee deelnemers en wedstrijden eenvoudig beheerd kunnen worden.

Het doel van dit project is om een centrale en gebruiksvriendelijke omgeving te bieden voor het organiseren van viswedstrijden, waarbij wedstrijdinformatie en deelnemersgegevens eenvoudig beheerd kunnen worden.
